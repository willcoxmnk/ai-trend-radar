# Pending proposals

The agent appends structural proposals here.  Decide on each by adding a line to `proposals/decisions.md`.  The agent records the outcome against the proposal on the next run.

## Template

```
### P-YYYY-MM-DD-NN - <add | merge | split | retire> - <short title>

- Type: add / merge / split / retire
- Affects: <trend or watch-list IDs>
- Proposed change: <exact change, including proposed title, definition and category for new trends>
- Evidence: <evidence IDs, with tier>
- Rubric threshold met: <which threshold in config/rubric.md>
- Reasoning: <two or three sentences>
- Outcome: pending
```
